Rule Set 1

Three Ground Rules

  • Bounds: 0 ≤ P(E) ≤ 1
  • Whole sample space: P(S) = 1
  • Impossible event: P(∅) = 0

Interpretation: probabilities are normalized belief over outcomes.

Main Target

Product Rule

P(A ∩ B) = P(A)P(B|A)
  • Read it as: "Probability of both = first event × conditional second."
  • Independent shortcut: P(A ∩ B) = P(A)P(B)

Fast example: two cards without replacement, both aces = 4/52 × 3/51.
